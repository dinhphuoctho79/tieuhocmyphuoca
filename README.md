# Khung Avatar V5 Lite

Phiên bản tối ưu nhẹ, tải nhanh và dễ cài đặt cho các đợt hưởng ứng phong trào.

## Không cần

- Node.js
- npm
- PHP
- MySQL
- Supabase
- Build

## Có

- Chọn ảnh / Camera
- Kéo ảnh
- Pinch zoom
- Xoay hai ngón
- Lật / căn giữa / vừa khung / lấp đầy
- Vùng an toàn Facebook
- Nhiều khung qua `frames.json`
- Xuất PNG 1024 / 2048
- Chia sẻ trên điện thoại
- Responsive

Xem `INSTALL.md`.
